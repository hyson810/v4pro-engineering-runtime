## "越跑越聪明"的机制

### 四个使能路径

1. **经验积累**：每轮 Hypothesis 的验证结果 → 更新置信度模型 → 未来假设更精准
2. **策略进化**：Meta-Cognitive Policy 从 v1.0 进化到 vN.0 → 越来越懂当前任务
3. **因果学习**：Causal Trace 发现"死胡同根因在第50轮"→ 避免同类陷阱
4. **模式沉淀**：Memory Cascade 把具体操作压缩为"经验教训"→ 下次直接检索

### 关键：这不是模型变聪明，是系统变聪明

模型权重不变。变的是：
- 系统对当前任务的理解越来越深（Meta-Cognitive Policy）
- 系统的决策质量越来越高（Causal Trace + Hypothesis）
- 系统的记忆越来越有价值（Memory Cascade）

**效果等价于"模型越跑越聪明"。**
